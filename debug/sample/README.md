# sample 函数精度验证

对核心层采样原语 `sample` 做统计精度验证：把给定 shots 下得到的
**经验分布**与态的**严格概率分布**对比，确认 shots 增大时经验分布
按采样理论期望收敛到严格分布。

- 被测对象：`sample(s, shots)` / `sample(s, qubits, shots)`
  （`src/ops/measure.jl`，逆变换采样：`cumsum` + `searchsortedfirst`）
- 测试脚本：[`convergence_test.jl`](convergence_test.jl)
- 运行：`julia --project=<VQC环境> debug/sample/convergence_test.jl`

## 方法

1. **构造已知严格分布的态**：n = 4，概率
   `pᵢ = 0.5 + 0.5·sin(3i)`（非均匀，且令基矢 idx 5、10 概率为 0，
   检验零概率分量不会被采到），经 `amplitude_encoding` 制备态。
2. **误差度量**：经验分布与严格分布的**总变差距离**
   `TV = 0.5·Σᵢ|p̂ᵢ − pᵢ|`。
3. **shots 扫描**：shots ∈ {10², 10³, 10⁴, 10⁵, 10⁶}，每组重复
   30 次，报告均值 ± 标准差。
4. **收敛判据**：采样理论期望均方误差 ∝ 1/shots，即
   TV 均值按 `1/√shots` 缩小、`std·√shots` 近似恒定。

## 结果（seed 固定，30 次平均）

### 全集采样

| shots  | mean TV | std TV | std·√shots |
|--------|---------|--------|------------|
| 10²    | 0.1307  | 0.0307 | 0.31       |
| 10³    | 0.0409  | 0.0105 | 0.33       |
| 10⁴    | 0.0123  | 0.0026 | 0.26       |
| 10⁵    | 0.0040  | 0.0008 | 0.25       |
| 10⁶    | 0.0013  | 0.0003 | 0.30       |

- shots 每 ×10，mean TV ÷≈3.2 ≈ √10 —— 精确符合 `1/√shots` 收敛；
- `std·√shots` 近似恒定 —— 波动纯为二项统计涨落，**无系统偏差**。

### 子集采样（非连续子集 `qubits = [3, 1]`，边缘分布）

| shots  | mean TV |
|--------|---------|
| 10²    | 0.0642  |
| 10³    | 0.0203  |
| 10⁴    | 0.0066  |
| 10⁵    | 0.0017  |
| 10⁶    | 0.0006  |

子集（边缘分布）路径同样按 `1/√shots` 收敛。

### 零概率分量

10⁶ shots 下，两个零概率基矢（0-based idx 5、10）的出现次数均为 0
——采样器不会向零概率分量泄漏计数。

## 结论

1. `sample` 的经验分布随 shots 增大按 `1/√shots` 收敛到严格分布，
   与二项采样理论一致；
2. 波动为纯统计涨落，无系统偏差；
3. 零概率基矢严格不出现；
4. 全集与非连续子集两条代码路径均验证通过。
